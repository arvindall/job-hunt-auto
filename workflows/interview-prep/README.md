# Interview Prep Tracker — LeetCode + Google Sheets + n8n + Claude

**Single source of truth**: Google Sheets. No scraping, no auth headaches.

**3 workflows**:
1. **Daily Problems** — 3 curated problems (Amazon/Meta L5, pattern rotation)
2. **Claude Tutor** — Stuck on a problem? Get HTML review + hints (no LeetCode scraping)
3. **Auto-Complete** — Set `Status = Completed` → auto-fill `Date_Completed`

**Foundation**: Problem statements pre-loaded into `Statement` column via LeetCode GraphQL (no auth required). [web:406]

## Quick Setup

1. **Run setup script**:
   ```bash
   python3 setup/create_interview_tracker.py  # Creates 6-tab sheet
   python3 setup/fetch_leetcode_descriptions.py  # Backfills Statements
   ```

2. **Start n8n**:
   ```bash
   cd workflows/interview-prep/docker
   docker compose up -d
   ```

3. **Import workflows**:
   - Copy JSONs from `n8n-workflows/` → n8n → Import
   - Configure credentials (Google Sheets, Gmail, Claude API)

4. **Test**:
   - Manual trigger → Gmail received → Sheet updated
   - Toggle Active → production

**Sheet URL**: Generated by `create_interview_tracker.py` (6 tabs: Questions, Dashboard, etc.).

## How It Works (Daily Flow)

```
8 AM: Workflow 1 → Email "Today's 3 problems: Sliding Window (Medium)"
You solve 2/3 → set Status = "In Progress" on #3 (Sheets app on phone)

Evening: Workflow 2 → Claude tutors #3 → appends HTML review to Notes
You solve it → Status = "Completed"

Hourly: Workflow 3 → Fills Date_Completed → Dashboard updates (42/150 done)
```

## Key Idea: Sheet is the Source of Truth

We keep a Google Sheet tab `Questions` with these columns:

| Column | Purpose |
|--------|----------|
| `Company` | Amazon, Meta, Apple, Shopify... |
| `Problem_Name` | Two Sum, LRU Cache... |
| `Difficulty` | Easy/Medium/Hard |
| `Pattern` | Sliding Window, DP, Graph... |
| `LeetCode_Link` | Match key for updates |
| `Statement` | Full problem text (GraphQL backfill) |
| `Status` | Not Started → In Progress → Completed |
| `Last_Reviewed` | Throttle knob (YYYY-MM-DD) |
| `Date_Completed` | Auto-filled by Workflow 3 |
| `Notes` | Append-only Claude reviews |

n8n reads/writes this sheet via the Google Sheets node operations. [web:256]

**Dashboard tab** auto-calculates metrics via formulas (created by setup script).

## Edge Cases Handled

| Issue | Solution |
|-------|----------|
| Stuck problem (multi-day) | `Last_Reviewed` throttle (2 days → 1 day knob) |
| HTTP node drops input | **Merge node** after Claude (joins sheet row + response) [web:704] |
| Node reference errors | No `$('Node Name')` — use merged `$json` only |
| Update Row "no output" | Match on `LeetCode_Link.trim()`, verify column exists [web:256] |
| Gmail no formatting | Claude outputs HTML directly |
| PC off (missed schedules) | Resumes on restart (no catch-up) [web:672] |

## Foundation: Problem Statements in the Sheet

Claude tutoring works best when it always receives the full problem statement.

We backfill `Statement`/`Problem_Description` using LeetCode's GraphQL endpoint `https://leetcode.com/graphql`. [web:406]

LeetCode sometimes places Cloudflare protections on the endpoint (403 "Enable JavaScript and cookies…"), so the backfill script includes rate limiting and retries. [web:612]

## Workflows

### Workflow 1 — Daily Problem Set

**Goal**: Send a daily set of problems (e.g., 3) filtered by company/difficulty and update the sheet.

**Actions**:
- Read `Questions` tab
- Filter: `Company = Amazon`, `Status = Not Started`
- Pick N by difficulty
- Email you the list
- Update selected rows to `In Progress` (optional)

(Workflow JSON stored under `n8n-workflows/`)

### Workflow 2 — Claude Tutor (no scraping)

**Goal**: For a single "In Progress" problem, send tutoring + store the review in `Notes`.

**Design constraints learned during troubleshooting**:
- Avoid brittle node references like `$('Some Node')` in Code nodes; it can error if a referenced node wasn't executed.
- HTTP Request nodes often return only response data, so you must explicitly **merge/carry the original row forward**. [web:704] [web:700]

**Recommended approach**:
```
Read In Progress → Filter Single Problem → Claude Explanation (HTTP) → Merge → Edit Fields → Combine Notes → Update Row → Gmail
```

`Edit Fields (Set)` is used to shape fields without losing required inputs. [web:510]

**Throttle edge case**:
- Add `Last_Reviewed` and use a knob (2 days now, 1 day later) so you don't spam yourself if you're stuck.
- Append to `Notes` so you keep history across follow-ups.

### Workflow 3 — Auto-fill Completion Date

**Goal**: You update `Status = Completed` from your phone or laptop; n8n fills `Date_Completed` automatically.

**Schedule (hourly)**:
- Read `Questions`
- Filter `Status == Completed AND Date_Completed empty`
- Set `Date_Completed = today`
- Update row (match on `LeetCode_Link`)

Google Sheets updates are done with "Update Row" + match column. [web:256]

## Troubleshooting

**"Referenced node doesn't exist"**
- Fix: Use Merge node after HTTP Request to combine inputs. [web:704] [web:700]

**Google Sheets Update Row "no output"**
- Verify: `LeetCode_Link` exists in sheet (exact match, trimmed).
- Columns exist (`Notes`, `Last_Reviewed`).
- Match column header spelling/case. [web:256]

**Cloudflare blocks GraphQL backfill**
- Slow down requests (1/sec), retry later, or use VPN. [web:612]

**Gmail plain text (no formatting)**
- Claude prompt: "Return valid HTML..."
- Gmail node: `Message Type = HTML`.

**PC off → missed schedules**
- Normal; resumes on restart (no auto-catch-up). [web:672]
